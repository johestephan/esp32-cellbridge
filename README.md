# esp32-cellbridge

[![Imagined by a human, generated by an AI](https://img.shields.io/badge/Imagined%20by%20a%20human-generated%20by%20an%20AI-8b5cf6?style=flat-square)](#-project-genesis)

> *"Imagined by a human, generated by an AI."*

Turn a **LilyGO T-A7670E R2** (ESP32-WROVER-E + SIMCom A7670E 4G LTE Cat1) — or **LilyGO T-A7608X** — into a self-hosted **SMS Gateway, Voice Alert / Caller-ID Bridge, Prepaid Credit Monitor, USSD Terminal, and 4G LTE HTTP/SOCKS5 Internet Proxy** with a built-in Web Dashboard, REST API, Webhooks, and **Home Assistant / Node-Red** integrations.

---

## Features

- **SMS Gateway (3GPP PDU Mode)**
  - Send & receive SMS via Web UI, REST API, or MQTT.
  - Full **GSM-7** (including `€`, `{`, `}`, `[`, `]`) and **UCS-2 / UTF-16BE** (emojis, accented characters) support.
  - Automatic **multipart / concatenated SMS** splitting (outgoing) and reassembly (incoming).
  - Decodes alphanumeric sender IDs (e.g., `Odido`, `DigiD`, `ING`).
  - Persists SMS & call history to LittleFS and auto-cleans SIM storage so the SIM card never fills up.
- **Voice Call Control & USSD**
  - Dial outgoing calls with optional **auto-hangup timer** (ideal for €0 missed-call alerts on prepaid!).
  - Real-time incoming caller ID (`+CLIP`) notifications via Webhook & MQTT.
  - Answer, Hangup (`AT+CHUP`/`ATH`), send DTMF tones (`AT+VTS`), and run USSD codes (`*101#`, etc.).
- **4G LTE Internet Proxy (HTTP/HTTPS & SOCKS5)**
  - Runs an **HTTP / HTTPS (`CONNECT`) proxy** (default port `8080`) and **SOCKS5 proxy** (default port `1080`) over the modem's `AT+NETOPEN` / `AT+CIPOPEN` stack — **without interrupting SMS or voice call URCs**.
  - Disabled by default so prepaid data credit is never used unintentionally.
  - Optional Basic / RFC-1929 proxy authentication and a built-in **Test 4G Public IP** tool.
- **Home Assistant & Node-Red Ready**
  - **MQTT + Home Assistant Auto-Discovery** (signal dBm, battery %, operator, last SMS, call state, 4G proxy switch, hangup/reboot buttons).
  - **JSON Webhooks** on incoming SMS and incoming calls (`X-Webhook-Secret` supported).
  - Ready-to-use examples in [`integrations/home-assistant/`](./integrations/home-assistant/) and [`integrations/node-red/`](./integrations/node-red/).
- **Web Dashboard, Login & OTA Updates**
  - Session-cookie **Login Page** (`/login`, default credentials `admin` / `nimda`) with in-app password change.
  - Self-contained responsive dark-mode Web UI (no external CDN required) with live **18650 Battery Voltage & Level** telemetry.
  - Primary + Fallback Wi-Fi support, plus **Captive Portal Wi-Fi Setup** (`ESP32-CellBridge-Setup`, password `12345678`) if no configured network is reachable or when holding **IO0** for 4 seconds.
  - Interactive **AT Command Console** and Over-The-Air (**.bin**) firmware updates directly from the Web UI.

## Hardware Notes & Warnings

Target hardware: **LilyGO T-A7670E R2** (`ESP32-WROVER-E`, 4MB Flash, 8MB PSRAM). Also supports **LilyGO T-A7608X** via the `lilygo-t-a7608x` PlatformIO environment.

1. **Insert the Nano SIM card BEFORE powering on** the board (the modem does not hot-detect SIM cards).
2. **Connect the LTE antenna** to the `SIM` IPEX connector before transmitting.
3. **Power supply**: Use a USB-A to USB-C cable or a 5V/2A power source (some USB-C-to-USB-C laptop ports do not negotiate 5V power properly on this board; LTE TX peaks require up to 2A).
4. **Battery**: Only use a single-cell 3.7V/4.2V Li-ion/LiPo (18650). Do **not** use LiFePO4 batteries.
5. **Reserved Pins**: Do not connect external wires to `GPIO4` (PWRKEY), `GPIO5` (Modem RST), `GPIO12` (Power EN), `GPIO25` (DTR), `GPIO26` (Modem TX), `GPIO27` (Modem RX), or `GPIO33` (RI). Remove any SD card before flashing if `GPIO2` interferes with upload.

## Odido Netherlands (Prepaid) Setup

1. Disable or note your SIM PIN:
   - You can unlock the SIM PIN once in a phone, **or** enter it in **Settings → SIM PIN** so the ESP32 unlocks it automatically on boot.
2. Pre-configured Odido NL APN defaults:
   - **APN**: `internet.mobiel` (username & password blank)
   - **SMSC**: Usually auto-loaded from SIM (`+31668400000` for Odido NL).
3. Remember: On a **prepaid SIM**, sending SMS or enabling the 4G Proxy consumes prepaid credit/data unless you have a bundle. The **4G Proxy is OFF by default** until you enable it.

## Build & Flash (PlatformIO)

### Prerequisites
- [VS Code](https://code.visualstudio.com/) + [PlatformIO IDE extension](https://platformio.org/install/ide?install=vscode), **or** PlatformIO CLI (`pio`).
- CH9102 USB-to-Serial driver (if required by your OS).

### Optional: Pre-configure Secrets
You can configure Wi-Fi, API keys, and APN via the Captive Portal after flashing, **or** copy the template before building:
```bash
cp include/secrets.h.example include/secrets.h
# Edit include/secrets.h (this file is in .gitignore and never committed)
```

### Build, Test & Upload
```bash
# Run native unit tests (SMS PDU/GSM-7/UCS-2 codec)
pio test -e native

# Build firmware for LilyGO T-A7670E R2
pio run -e lilygo-t-a7670e-r2

# Flash via USB
pio run -e lilygo-t-a7670e-r2 -t upload

# Open serial monitor (115200 baud)
pio device monitor
```
*(If using a LilyGO T-A7608X board, replace `lilygo-t-a7670e-r2` with `lilygo-t-a7608x`.)*

If flashing fails to sync, hold **IO0**, press & release **RST**, then release **IO0** to enter manual download mode.

### First Boot
1. If no Wi-Fi credentials are configured, the ESP32 creates an AP:
   - **SSID**: `ESP32-CellBridge-Setup`
   - **Password**: `12345678`
2. Connect and open `http://192.168.4.1/` and sign in (default: **`admin`** / **`nimda`**).
3. Go to **Settings & OTA**, change your login password, enter your Primary (and optional Fallback) Wi-Fi SSID & password, set an **API Key**, and enter your **SIM PIN** (if locked), then click **Save Configuration**.
4. Once connected to your LAN, open `http://esp32-cellbridge.local/` (or its LAN IP).

## REST API Reference

If `api_key` or `web_pass` is configured, include one of:
- Header `X-API-Key: <your-api-key>`
- Header `Authorization: Bearer <your-api-key>`
- HTTP Basic Auth (`web_user` / `web_pass`)

| Method | Endpoint | Description |
| --- | --- | --- |
| `GET` | `/api/health` | Unauthenticated health check (`{"ok": true, ...}`) |
| `POST` | `/api/auth/login` | Log in with `{"username", "password"}` (sets session cookie) |
| `POST` | `/api/auth/logout` | Clear current session cookie |
| `POST` | `/api/auth/password` | Change password: `{"current_password", "new_password"}` |
| `GET` | `/api/status` | Modem, SIM, signal, battery, Wi-Fi, LTE IP & proxy stats |
| `GET` | `/api/sms` | List SMS (`?direction=in\|out&unread=true&limit=50`) |
| `POST` | `/api/sms/send` | Send SMS: `{"to": "+31612345678", "message": "Hello!"}` |
| `POST` | `/api/sms/scan` | Trigger immediate scan of SIM SMS storage |
| `POST` | `/api/sms/read` | Mark read: `{"id": 12}` or `{"all": true}` |
| `DELETE` | `/api/sms` | Delete `?id=12` or clear all SMS |
| `GET` | `/api/calls` | List recent call history |
| `POST` | `/api/call/dial` | Dial call: `{"to": "+31612345678", "timeout_sec": 15}` |
| `POST` | `/api/call/answer` | Answer ringing call |
| `POST` | `/api/call/hangup` | Hang up active/ringing call |
| `POST` | `/api/call/dtmf` | Send DTMF digits: `{"digits": "1234#"}` |
| `GET` | `/api/balance` | Get cached prepaid balance & last check metadata |
| `POST` | `/api/balance/check` | Query prepaid balance (Odido NL default: SMS `SALDO` to `1144`) |
| `POST` | `/api/ussd` | Send USSD code: `{"code": "*101#"}` |
| `POST` | `/api/at` | Execute raw AT command: `{"command": "AT+CSQ"}` |
| `GET` | `/api/proxy/status` | 4G proxy status & traffic counters |
| `POST` | `/api/proxy/toggle` | Enable/disable 4G proxy: `{"enabled": true}` |
| `POST` | `/api/proxy/test` | Fetch public IP over 4G LTE (`api.ipify.org`) |
| `GET` | `/api/config` | Read configuration (secrets masked) |
| `POST` | `/api/config` | Update configuration |
| `POST` | `/api/modem/reboot` | Reset cellular modem (`AT+CRESET`) |
| `POST` | `/api/system/reboot` | Reboot ESP32 |
| `POST` | `/api/ota` | Multipart `.bin` firmware upload |

### Quick `curl` Examples
```bash
# Send an SMS
curl -X POST http://esp32-cellbridge.local/api/sms/send \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"to": "+31612345678", "message": "Server room temp > 35°C!"}'

# Place a 15-second ring-alert call
curl -X POST http://esp32-cellbridge.local/api/call/dial \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"to": "+31612345678", "timeout_sec": 15}'

# Route curl traffic over the 4G LTE HTTP proxy (when enabled)
curl -x http://esp32-cellbridge.local:8080 https://api.ipify.org

# Route curl traffic over the 4G LTE SOCKS5 proxy
curl --socks5 esp32-cellbridge.local:1080 https://api.ipify.org
```
